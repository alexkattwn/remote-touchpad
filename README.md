# Remote Touchpad

Программа, которая превращает экран смартфона в беспроводной тачпад для управления курсором мыши на компьютере.

## Как это работает

1. Приложение запускается на ПК, определяет локальный IP-адрес в сети и генерирует уникальную ссылку с токеном безопасности в виде **QR-кода**.
2. Вы сканируете QR-код камерой смартфона.
3. На телефоне открывается веб-страница (сенсорная панель). Все касания экрана передаются на ПК через **WebSockets**, перемещая курсор мыши.

> **Важно:** Компьютер и смартфон должны быть подключены к одной Wi-Fi сети (к одному роутеру).

## Как собрать проект в .exe файл

Для сборки на компьютере должны быть установлены **Go (1.20+)** и **Node.js (с npm)**.

### 1. Установка сборщика Wails

Если утилиты Wails еще нет, установите её через терминал:

```bash
go install [github.com/wailsapp/wails/v2/cmd/wails@latest](https://github.com/wailsapp/wails/v2/cmd/wails@latest)
```

### 2. Подготовка зависимостей

Перейдите в папку проекта и обновите модули Go:

```bash
go mod tidy
```

### 3. Компиляция приложения

Запустите команду сборки. Флаг -H=windowsgui скроет черное консольное окно при запуске программы:

```bash
wails build -clean -platform windows/amd64 -ldflags "-w -s -H=windowsgui"
```

### 4. Результат

После завершения сборки готовый автономный файл появится по пути:
remote-touchpad/build/bin/Remote Touchpad.exe
