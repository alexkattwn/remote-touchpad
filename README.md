# Touchpad (Remote Mouse Control)

Простое приложение, которое позволяет управлять мышью компьютера с телефона через браузер (по локальной сети).

---

## 🚀 Возможности

- Управление курсором мыши
- Левый / правый клик
- Двойной клик
- Скролл
- Подключение через браузер (без установки клиента)
- QR-код для быстрого подключения

---

## 📦 Требования

- Go **1.20+**
- Windows (для управления мышью)

---

## 📁 Структура проекта

```
project/
├── cmd/app/            # точка входа (main.go)
├── internal/
│   ├── server/         # запуск HTTP сервера
│   ├── ws/             # WebSocket обработка
│   ├── mouse/          # управление мышью (Windows API)
│   ├── auth/           # генерация токена
│   └── utils/          # утилиты (IP и др.)
├── static/             # фронтенд (HTML/JS)
├── go.mod
└── README.md
```

---

## ⚙️ Как собрать проект

### 1. Клонировать репозиторий

```bash
git clone https://github.com/alexkattwn/remote-touchpad.git
cd remote-touchpad
```

---

### 2. Скачать зависимости

```bash
go mod tidy
```

---

### 3. Запустить в режиме разработки

```bash
go run ./cmd/app
```

После запуска в консоли появится:

- ссылка вида: `http://192.168.x.x:8080/?token=XXXX`
- QR-код

Открой ссылку на телефоне (в той же сети Wi-Fi).

---

## 🏗️ Сборка `.exe`

### Базовая сборка

```bash
go build -ldflags="-s -w" -o touchpad.exe ./cmd/app
```

---

### Скрыть консоль (как у обычных приложений)

```bash
go build -ldflags="-s -w -H=windowsgui" -o touchpad.exe ./cmd/app
```

---

### Сборка под Windows с другой ОС

```bash
GOOS=windows GOARCH=amd64 go build -ldflags="-s -w" -o touchpad.exe ./cmd/app
```

---

## ▶️ Запуск

Просто запусти:

```bash
touchpad.exe
```

Далее:

1. Открой ссылку из консоли **или**
2. Отсканируй QR-код с телефона

---

## 🔐 Безопасность

- Каждый запуск генерирует уникальный `token`
- Подключиться можно только с правильным токеном
- Разрешён только **один активный клиент**

---

## 🧩 Как это работает

1. Сервер запускается на ПК (`:8080`)
2. Телефон подключается через WebSocket
3. Движения/клики отправляются в JSON
4. ПК выполняет действия через Windows API
